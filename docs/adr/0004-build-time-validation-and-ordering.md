# 领域模型封版：构建时校验与排序规则

五个边界决策一次性封版：(1) 价格策略为两态——填价格或没填，没填即渲染 "Contact for price"，无显式询价声明字段；(2) 空分类在构建时从筛选器和路由中隐藏，不产生空落地页；(3) 每个分类拥有独立落地页 `/products/<slug>/` 及可选介绍文案，作为 SEO 着陆页；(4) 商品及精选商品在页面的展示顺序由 Product Config JSON 文件内的排列顺序决定，不设 order 数字字段；(5) 商品缺图或缺分类时构建直接失败，把配置错误拦截在部署之前。理由：这是纯配置驱动站点，所有可枚举的异常状态都应在构建期暴露而非线上兜底。
